비밀번호와 JWT는 화면에 출력하지 않습니다. 파일 내용은 테스트용 더미 바이트이며 개인정보를 포함하지 않습니다.

0. API_BASE (실행 대상 Worker)

이 페이지는 same-origin 경로 /local-api/...로만 호출합니다. Vite가 이를 로컬 Worker (http://127.0.0.1:8787)로 중계하므로 브라우저 CORS 문제가 없습니다. 로컬에서 npx wrangler dev --port 8787을 먼저 실행하세요. backend/.dev.vars에 실제 DATABASE_URL이 있어야 DB 연결이 됩니다.

이 페이지에서는 운영 URL을 사용할 수 없습니다. 운영 core 테스트는 기존 phase3-test.html을 사용하세요.

4. Storage 자동 테스트 실행


  

    photo 1~3 업로드 → 4번째 409 →
    proof 업로드 → 목록 → public photo 조회 →

    순서대로 실행합니다.

6. 승인 게이트 시도 (주의: 실제 심사 동작)


  

    이 버튼은 실제 관리자 승인 API를 호출합니다.
    proof가 있는 신청이면 실제로 가게가 발행(published)될 수 있습니다.
    proof가 없는 신청이면 409 OWNER_PROOF_REQUIRED로 차단됩니다.
    관리자(operator/admin) 계정으로 로그인한 상태에서만 동작합니다.
