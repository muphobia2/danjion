단지온 PHASE 4 우리단지 E2E

비밀번호와 JWT는 화면에 출력하지 않습니다. 순서: GUEST → user 7(주민) → user 1(관리자) → user 7(삭제). JWT와 단계별 ID는 모드별 namespace로 sessionStorage에만 임시 저장합니다. JWT·비밀번호는 화면에 출력하지 않습니다.

0. 실행 모드

기본값은 LOCAL입니다. LOCAL은 /local-api/...를 로컬 Worker로, PRODUCTION은 /prod-api/...를 실제 배포 Worker로 중계합니다 (same-origin, CORS 없음).

PRODUCTION 모드에서 글쓰기·삭제·승인은 실제 데이터를 만듭니다. 확인란 없이 mutation 버튼은 차단됩니다.

2. GUEST 읽기 (로그아웃 상태 권장)


  

    공지·아파트소식·주민소식 목록/상세, 이웃대화 목록은 200.
    이웃대화 상세·글쓰기·댓글·반응은 401/403.
  


  

  







  
3. user 7 — 주민 작성 플로우


  

    user 7 로그인 후 실행.
    talk 작성→수정→댓글→답글→반응→중복 반응→2단 답글 차단→
    주민소식 신청 2건(승인용/거절용).
  


  

  







  
4. user 1 — 관리자 심사 + 권한 차단


  

    user 7 로그아웃 → user 1 로그인 후 실행.
    user 7 글에 대한 일반 수정/삭제 403 확인,
    제보 승인/거절, 승인글 공개 확인.
  


  

  







  
5. user 7 — 본인 글 삭제


  

    user 1 로그아웃 → user 7 로그인 후 실행.
